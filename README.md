# 🔥 VIP Models & Premium Video Platform

A sleek, seductive, high-converting VIP Models showcase and premium video landing page with a comprehensive Admin Panel.

---

## 🚀 Quick Start Guide

### 1. Install & Run Server
```bash
# In the project directory
npm install
npm start
```

### 2. Access the Platform
- **Public VIP Landing Page**: [http://localhost:3000](http://localhost:3000)
- **Admin Control Panel**: [http://localhost:3000/admin](http://localhost:3000/admin)
- **Default Master Admin PIN / Password**: `admin123`

---

## 🌟 Key Features

### 💋 Seductive & Professional Front-End Landing Page
- **High-Impact Luxury Aesthetic**: Dark glassmorphism with ruby-red neon glow, smooth hover micro-animations, and gold VIP accents.
- **Dynamic Model Cards**: High-res portraits, status badges (*Online Now*, *Live Streaming*), rating, video counts, location, and tags.
- **High-Converting Action Button**: Glowing **"🔥 Watch All My Premium Videos - Click Here"** button on every card with real-time click tracking and instant redirection to the model's premium content / private VIP feed.
- **Interactive Quick-View Modal**: View model galleries, detailed bios, and instant access links.
- **Smart Filtering & Search**: Instant filter tabs (*All Models*, *Featured*, *VIP Exclusive*, *Top Rated 5.0*, *New Arrivals*) + keyword search.
- **18+ Age Gate Verification**: Seductive entry disclaimer modal complying with adult content guidelines.

### 👑 Complete Admin Management Dashboard (`/admin`)
- **Real-Time Analytics**: Track total models, active models, video clicks, and top-performing models leaderboard.
- **Model Manager (CRUD)**:
  - Add, edit, and delete model profiles.
  - **Upload photos directly from your computer** or paste external image URLs.
  - Set custom **Premium Video Destination URLs** per model (OnlyFans, Fansly, Telegram, custom paywalls, or private streams).
  - Toggle visibility (*Visible / Hidden*) and *Featured Spotlight* status.
- **Site & Link Customizer**:
  - Update Brand Name, Hero Headlines, Subtitles, and Top Marquee Announcement.
  - Customize the Action Button text (e.g., *"🔥 Watch All My Premium Videos - Click Here"*).
  - Change default global fallback link and Telegram VIP channel.
  - Change the master admin password/PIN anytime.
